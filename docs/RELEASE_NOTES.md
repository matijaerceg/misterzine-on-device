**Choose a view directly**

Press **Y** in the game list to open the new view chooser. Browse with Up/Down, select with **A**, or cancel with **B**. The current view is highlighted, and long lists scroll.

**Edit available views…** stays at the bottom of the popup. It opens the same editor as **Options → List → Available views**, with standard and genre views together. Your existing choices and startup preferences are kept.

**Also changed**

- **Mature games** now defaults to **Hide**, matching the release tracker. Choose Show or Pixelate in Options → List to include them. Saved Pixelate and Hide choices remain; a previous Show choice switches to Hide once on upgrade because Show used to be stored as an unset value.

Tested on MiSTer Pi.
