Figtree lettering and deeper glints on the screensaver.

- **Figtree letters:** the scrolling MISTERZINE lettering is now traced from
  Figtree Black, with its curves, instead of hand-drawn block capitals. Only
  the traced outlines ship; the font itself is not included (SIL Open Font
  License, credited in the third-party notices). A generator script can
  re-trace the letters from any font.
- **More glints:** besides the violet and lime lights, each face of the letters
  now meets dim, fast glints running the other way: a faded green one that the
  left-facing edges cross twice, and a gray one on the right-facing edges. The
  lime light stands more upright, so its glint travels faster, and is slightly
  dimmer. All lights stay still; every glint moves only with the lettering's
  scroll, and the edges stay under 40% brightness.

No settings change. The effect costs nothing measurable on the device.

Existing installations can update through Update All/Downloader. Reopen
MisterZine after updating. Favorites, settings and filter choices are preserved.

For a new installation, follow the
[installation guide](https://github.com/matijaerceg/misterzine-on-device#install-once).
Run **MisterZine-Setup** from Scripts once, then open MisterZine from the main menu.
