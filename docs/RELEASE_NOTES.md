**Why a game is not on your card**

Details now says, under **Source**, whether Update All brings a game's source to your card: it already fetches it, it carries it but the toggle is off in Update All's settings, or it does not include it and the line names the `downloader.ini` section to add.

For example: a bazset game that is not on your card reads "Update All: does not include bazset; add a [bazset/MiSTer_BAZSET] section to downloader.ini", and a theypsilon game reads "switched off on this card; turn it on in Update All's settings".
