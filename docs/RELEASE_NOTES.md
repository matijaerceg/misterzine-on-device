Chrome edges on the screensaver lettering.

- **Glinting outline:** the scrolling MISTERZINE letters now carry a one-pixel
  chrome edge. Two still lights stand on the screen, a violet one that only the
  left-facing edges reflect and a lime one for the right-facing edges. As the
  letters slide through them the outline glints, and the glint travels along
  each edge purely with the lettering's own motion, up along edges leaning one
  way and down along the other. Away from the lights the edges stay black, and
  the glint never exceeds 40% brightness, so the saver stays as dim and
  tube-safe as before.

No settings change. The effect costs nothing measurable on the device.

Existing installations can update through Update All/Downloader. Reopen
MisterZine after updating. Favorites, settings and filter choices are preserved.

For a new installation, follow the
[installation guide](https://github.com/matijaerceg/misterzine-on-device#install-once).
Run **MisterZine-Setup** from Scripts once, then open MisterZine from the main menu.
