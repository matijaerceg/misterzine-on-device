**Same-game groups**

A game the catalogue has on two or three cores can now be one line in the list, with the number of versions after its name: press A to open it and pick a core. It is a beta for now, shown when **Show beta features** is on in Options -> Operation.

For example: Rainbow Islands runs on both bazset's and Jotego's cores, so it reads "Rainbow Islands (2)" instead of taking two lines.

**Added**

- Same-game groups in the list, with **Show beta features** on: one line per game, and A opens it to show each core's version.
- Button mapping and the ROM report no longer need **Show beta features**: set up any controller in Options -> Controls, and get the list of ROM files to add or replace from Options -> Data -> Rescan card.

**Fixed**

- Button mapping takes the place of the **Button labels** and **OK button** options; what you chose there still applies to a controller you have not mapped.
