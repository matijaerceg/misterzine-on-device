Smoother scrolling, steadier Options previews, and more HDMI layout choices

- Held list scrolling at 20 and 30 Hz can now move smoothly between rows. Toggle Smooth scrolling beneath Scroll speed and compare both behaviors in the animated preview.
- Options hints and previews stay the same height, with four lines in both orientations.
- Collapse Options sections to keep the page tidy; section choices are remembered during the session.
- HDMI picture changes apply live. New installations default to Full display; existing installations keep their saved mode. Widescreen artwork and portrait captions also get layout improvements.
- Restart MisterZine directly after Update All replaces the app.
