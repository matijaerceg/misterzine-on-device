# MisterZine codes

Everyone installs the same MisterZine and gets the same updates. A code from
the [MisterZine Patreon](https://www.patreon.com/MisterZine) unlocks the
Supporter extras, forever, on every device you enter it on. Enter it in
Options -> Operation -> Your access.

Each code is named after a month. The month says which extras the code covers:
every Supporter extra introduced through that month. It is not an expiry date,
and you do not need to stay subscribed. A newer code includes everything an
older one does, and entering an older code never takes anything away.

The codes themselves are shared only in the Patreon posts. This page lists
what each one unlocks.

| Code | Unlocks | Since |
| --- | --- | --- |
| **Oct 2026** | Themes: colour schemes for the whole app, from presets such as Amber, DMG and Vaporwave to a custom one you edit yourself. Group tallies: the number of games in each group, printed beside the group name. | v1.2.3 |

Both are betas at the moment, so they also need **Show beta features** switched
on, in Options -> Operation. Free betas such as Button mapping and the ROM
report need only that switch and no code.

More in the [user guide](USER_GUIDE.md#misterzine-codes-and-optional-features).
